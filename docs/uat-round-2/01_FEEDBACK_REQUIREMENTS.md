# 01 — Feedback Requirements (UAT Round 2)

ที่มา: Crude Feedback 12/11/69 (PDF) + spec "WOMS — UAT ROUND 2" · วันที่ทำ 14 พ.ย. 2569

| ID | Feedback (ลูกค้า) | Requirement ที่ตีความ | Scope |
|---|---|---|---|
| UAT2-01 | ช่างเสนอวันเวลา อยากเห็นปฏิทิน | ตอนเสนอวัน แสดงปฏิทินงานของช่างที่รับคิว 14 วัน (ว่าง/1–2 งาน/3+ งาน) กดวันเพื่อเลือก | IN |
| UAT2-02 | รุ่นเครื่องไม่มี import | นำเข้ารุ่นเครื่อง (ข้อมูลหลัก) จาก Excel มี template + ตรวจก่อนบันทึก (dry-run) | IN (ไม่แตะ import ของคลังเครื่อง) |
| UAT2-03 | Package PM ในข้อมูลพื้นฐาน | — | OUT OF SCOPE (PM) |
| UAT2-04 | ช่างใช้เบอร์โทรเป็น username | Login ด้วยเบอร์โทร + รหัสผ่าน (Owner อนุมัติ: ยังต้องมีรหัสผ่าน · เบอร์ห้ามซ้ำ · บัญชีเดิมไม่เปลี่ยน) | IN |
| UAT2-05 | เซลล์ในข้อมูลพื้นฐานยังไม่ผูกกับ username | รายชื่อเซลล์ (ตัวเลือก) = ค่าใน master ∪ ผู้ใช้ที่เป็นเซลล์และใช้งานอยู่ | IN |
| UAT2-06 | Sale ไม่มีให้ใส่ทีมในผู้ใช้ | หน้าผู้ใช้แสดงทีมเซลล์ของผู้ใช้ Sales และกำหนด/ย้าย/นำออกได้ | IN |
| UAT2-07 | รูปในแชทกดโหลดไม่ได้ | ปุ่มดาวน์โหลดบนรูปและในหน้าดูรูปใหญ่ ใช้ชื่อไฟล์เดิม | IN |
| UAT2-08 | ใส่รูปหน้างานในเปิดคิวได้ | แนบรูปหน้างานตอนเปิดคิว/ร่างคิว/หน้าคิว | IN |
| UAT2-09 | เลือกเครื่องจากคลังในหน้าเปิดคิว: เครื่องที่ไม่มีในคลังยังโผล่ / เลือกประเภทแล้วเครื่องหาย · ถ้าไม่มีว่างในคลังไม่ต้องแสดง | หน้าเปิดคิว (งานติดตั้ง / ยังไม่เลือกประเภทงาน) แสดงเฉพาะเครื่องสถานะ "ในคลัง" และรุ่นที่มีเครื่องว่างเท่านั้น | IN |
| UAT2-10 | ส่วนเพิ่มเครื่องแยกไม่ออกว่ากดไปหรือยัง | แถวที่เลือกแล้วเห็นชัด + จำนวนที่เลือก | IN |
| UAT2-11 | แชท search ให้ครบ | ค้นด้วยชื่อผู้ส่งได้ (เดิมค้นข้อความ/เลขคิว/JN/Reply/ชื่อไฟล์/การ์ดคิวได้แล้ว) | IN |
| UAT2-12 | Icon ประจำ user | แสดงรูปประจำผู้ใช้ (หรือวงกลมสี+อักษรแรก) เพิ่มในรายการคิว (เซลล์/ช่าง) | IN |
| UAT2-13 | หา JN ในใบคิวไม่เจอ | JN แสดงชัดในหัวคิว ข้อมูลงาน รายการ บอร์ด การ์ดแชท · ยังไม่ออก JN แสดงสถานะ | IN |
| UAT2-14 | เลื่อนงาน: ต้องมีปุ่มแจ้งเลื่อนแล้วส่งกลับเช็คคิวเลย · แสดงสถานะ+เหตุผลชัด แยกจากพักงาน · กลับไปเลือกช่าง | ปุ่ม "แจ้งเลื่อนงาน" ในขั้นของงาน → ส่งกลับเข้าคิว (API เดิม) → ไปหน้าคิวขั้นเลือกช่าง · ป้าย "เลื่อนวันเข้า" แยกจาก "พักงาน" โดยไม่เพิ่ม status ใหม่ | IN (ส่วน "status แยกในฐานข้อมูล" = BLOCKED FOR BUSINESS DECISION) |
| UAT2-15 | เก็บรูปหน้างานในใบงาน/ใบคิว | รูปหน้างานเก็บถาวรคู่คิว · ใบงานที่เปิดจากคิวเปิดดูได้ | IN |
| UAT2-16 | หน้ารับเครื่องเข้าคลัง | — | OUT OF SCOPE (คลังเครื่อง) |
| UAT2-17 | สัญญาเช่ารูปแบบไม่แน่นอน | ย่อหน้าภาษาไทยจัดชิดขอบแบบกระจายตัวอักษร (ช่องไฟสม่ำเสมอ) | IN (ต้องให้ลูกค้ายืนยันด้วยตา) |

## อัปเดต 14 พ.ย. 2569 (รอบ Master Execution) — การตัดสินใจที่ Owner อนุมัติแล้ว

| Decision | ผลต่อ Requirement |
|---|---|
| D-R2-01 | UAT2-09: งานติดตั้ง = เครื่องว่างในคลังเท่านั้น (Backend ตรวจ) · งานซ่อม/บริการ = เครื่องที่อยู่กับลูกค้า/สาขาของคิว ไม่ต้องว่างในคลัง ไม่เห็นเครื่องลูกค้ารายอื่น |
| D-R2-02 | UAT2-14: ไม่เพิ่มสถานะใหม่ · ใช้ HOLD เดิม แยกป้าย "เลื่อนวันเข้า" ในหน้าจอ · ต้องมี audit ที่ใบงาน (ผู้ทำ เวลา เหตุผล JN การเปลี่ยนสถานะ) |
| D-R2-03 | UAT2-17: สัญญาเช่าใช้ฟอนต์ที่ฝังมากับระบบฟอนต์เดียว · ต้องให้ลูกค้ายืนยันด้วยตา |
| D-R2-04 | UAT2-08/15: ลบรูปหน้างาน — ก่อนส่งคิว: เจ้าของร่าง/Admin · หลังส่ง: เฉพาะ Admin + เหตุผล + audit · ไม่ลบหลักฐานเงียบ |
