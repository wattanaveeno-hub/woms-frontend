# P4-06 UAT2-18 — ข้อกำหนดเพิ่มเติมในสัญญาเช่า (Implementation)

## ข้อมูล (backward-compatible)
- ฟิลด์ใหม่ไม่บังคับ `additionalClauses?: Array<{ order: number; text: string }>` ใน `contracts`
- สัญญาเดิมไม่มีฟิลด์ = ไม่มีข้อกำหนด · API คืน `additionalClauses: []` เสมอ · **ไม่มี migration** · สร้างใหม่โดยไม่มีข้อกำหนด → ไม่เขียนฟิลด์ลงเอกสาร

## กติกา (`src/domain/contractClauses.ts` · หน้าเว็บ `src/lib/contractClauses.ts` ใช้กติกาเดียวกัน)
| กติกา | ค่า |
|---|---|
| ใช้กับ | สัญญาเช่า (RENTAL) เท่านั้น · ประเภทอื่นส่งมา → 400 |
| แก้ไขได้เมื่อ | สถานะ “ร่างสัญญา” (DRAFT) เท่านั้น · สัญญาที่ออกแล้ว → 409 “… ระบบยังไม่มีขั้นตอนแก้ไขสัญญา (amendment)” |
| Admin แก้ | ส่งคำขออนุมัติ 202 (เหมือนการแก้สัญญาอื่น) · ถ้าสัญญาออกแล้ว → 409 ตั้งแต่ตอนขอ (ไม่สร้างคำขอที่ทำไม่ได้) |
| จำนวน | ≤ 20 ข้อ |
| ต่อข้อ | 1–1,000 ตัวอักษร · ≤ 20 บรรทัด |
| รวม | ≤ 8,000 ตัวอักษร |
| เนื้อหา | ข้อความธรรมดาหลายบรรทัด · ห้ามแท็ก HTML/สคริปต์ (`<tag`, `</`, `<!`, `<?`) · เครื่องหมาย `<` `>` ทั่วไปได้ · ตัดอักขระควบคุม/อักขระซ่อนทิศทาง · NFC · CRLF→LF |
| ลำดับ | server จัด `order` ใหม่ 1..n ตามลำดับที่ส่ง · ลำดับซ้ำ → 400 |
| ประวัติ | แก้แล้วเพิ่ม history EDIT บนสัญญา · audit `additionalClauses` บันทึก “N ข้อ (ความยาว) #hash” ไม่ใส่ข้อความเต็ม |
| ต่อสัญญา | ฉบับใหม่ยกข้อกำหนดชุดเดิม (OD-P4-02) |

ขีดจำกัดเลือกจากการพิมพ์จริง: ข้อ 1,000 ตัวอักษร/20 บรรทัด สูงไม่เกิน 1 แผ่น และกรณีเต็มขีดจำกัด (8×1,000 และ 20×400) จัดหน้าได้ไม่ทับลายเซ็น (`07_CONTRACT_PDF.md`)

## หน้าจอ
- สร้างสัญญา: ส่วน “ข้อกำหนดเพิ่มเติมในสัญญา” (เฉพาะสัญญาเช่า) · เพิ่ม/แก้/ลบ/เลื่อนขึ้น-ลง · หลายบรรทัด · ตัวนับตัวอักษร · ดูตัวอย่าง · ตรวจก่อนส่ง (`ContractClausesEditor.tsx`, `ContractForm.tsx`)
- รายละเอียดสัญญา: การ์ดหัวข้อเดียวกัน แสดงตามลำดับ เลขข้อเดียวกับเอกสารพิมพ์ · ปุ่มแก้ไขเฉพาะสัญญาร่าง + `contracts:edit` · สัญญาออกแล้วแสดง “แก้ไขไม่ได้” (`ContractClausesCard.tsx`)
- แสดงผลเป็นข้อความเสมอ (React escape · ไม่ใช้ innerHTML)

## เอกสารพิมพ์ (`RentalContractDocument.tsx`, `RentalContractScreen.tsx`)
- หัวข้อ “ข้อกำหนดเพิ่มเติมในสัญญา” ต่อจากข้อ 5 **ก่อน** ย่อหน้า “เพื่อเป็นหลักฐาน…” และส่วนลงนาม
- เลขข้อต่อจากเนื้อสัญญา: 6, 7, … (ไม่ชนกับ “ข้อตกลงและเงื่อนไขท้ายสัญญา” หน้า 2 ซึ่งเป็นชุดเลข 1–15 ภายใต้หัวข้อแยก) · เทสต์ตรวจว่าเลขข้อสุดท้ายของแม่แบบ = 5
- จัดหน้าจากความสูงจริง (แผ่นวัดที่ซ่อนไว้ ไม่พิมพ์): ข้อที่ไม่พอในหน้า 1 ขึ้นแผ่นต่อเนื่อง (หัว “สัญญาเลขที่ … (ต่อ)” + ป้ายฉบับ + ท้ายกระดาษเดิม) · ไม่ตัดกลางข้อ · ลายเซ็นอยู่แผ่นเดียวกับข้อสุดท้ายเสมอ (ยกข้อสุดท้ายไปด้วยถ้าจำเป็น) · ไม่ย่อตัวอักษรหน้า 1
- ไม่มีข้อกำหนด → ใช้เส้นทางเดิมทุกประการ (2 แผ่น/ฉบับ)
- ฟอนต์ Sarabun ที่ฝังมากับระบบ (เดิม) · ข้อความแม่แบบสัญญาไม่ถูกแก้แม้แต่ตัวอักษรเดียว
- PDF จากเซิร์ฟเวอร์ (`/document.pdf`, pdfkit — ใบสรุปสัญญา ไม่ใช่แบบฟอร์มสัญญาเช่า) ไม่ได้เพิ่มข้อกำหนด (OD-P4-04)
