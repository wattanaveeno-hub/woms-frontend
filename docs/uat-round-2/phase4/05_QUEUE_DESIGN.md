# P4-05 Queue — Design gap

เทียบ `Queue.dc.html`:
- แถวตัวกรองเดียว: ค้นหา + ช่าง + วันนัด (กว้าง 170px บน desktop) + เจ้าของงาน — เดิมช่องวันนัดขึ้นแถวใหม่เต็มความกว้าง
- คำอธิบายหัวหน้า: บอร์ด “คำขอที่ยังไม่เป็นใบงาน · เรียงจากรอนานที่สุด” (ตรงกับการเรียงจริงของบอร์ด) · ตาราง “… เรียงจากอัปเดตล่าสุด” (ตรงกับ API)
- การ์ดบนบอร์ดมีปุ่มขั้นถัดไปตาม design: เลือกช่าง / ดูคิว / รับคิว / ลูกค้ายืนยันแล้ว / เปิดงาน + ปุ่ม “โทร” (tel:) เฉพาะคิวรอลูกค้ายืนยัน
  - ปุ่มเป็นลิงก์ไปหน้ารายละเอียดคิว **ไม่เรียก API เอง** — การทำงานจริง/สิทธิ์/state machine ยังอยู่หน้ารายละเอียดเหมือนเดิม
  - การ์ดยังกดทั้งใบได้ (stretched link) · ไม่มี interactive ซ้อนกัน (ตรวจแล้ว 0 จุด)
- คงไว้: คอลัมน์สถานะ 5 ขั้น · ตัวนับ · ตัวกรอง · ค้นหา · ปุ่มบอร์ด/ตาราง · การจัดช่าง/เลื่อนวัน/คอนเฟิร์ม/ประวัติ · สิทธิ์ตามบทบาท
