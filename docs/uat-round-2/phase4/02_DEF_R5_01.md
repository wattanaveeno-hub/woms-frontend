# P4-02 DEF-R5-01 — Job list stage projection

## ปัญหา
`GET /api/jobs` และ `GET /api/jobs/:id` คืน `stage` ที่เก็บไว้ในเอกสาร ส่วน stage SUBMITTED คำนวณจากรายการส่งงาน (`#ส่งงาน`) ที่สถานะ PENDING เฉพาะใน `GET /api/jobs/:id/stage` → หน้า /jobs แท็บ “รอตรวจปิด” = 0 เสมอ และปุ่ม “ตรวจปิด” ไม่ขึ้น

## การแก้ (backend)
- `src/mongo/chatRepo.ts` — `pendingSubmissionJobIds(jobIds)` อ่านรายการส่งงาน PENDING ของหลายใบงานใน query เดียว (projection เฉพาะ jobId)
- `src/routes/jobs.ts` — `withProjectedStage(jobs)` ใช้ `deriveStage(status, stage เดิม, มีรายการส่งงานค้าง)` ชุดเดียวกับ `/:id/stage` · ใช้กับ `GET /` และ `GET /:id` · query ล้มเหลว → คงค่าเดิม (ไม่ทำให้รายการพัง) · ไม่เขียนฐานข้อมูล · ไม่เปลี่ยน state machine
- ขอบเขตสิทธิ์/ตัวกรอง/การเรียงลำดับเดิมไม่เปลี่ยน (คำนวณหลังกรองแล้ว)
