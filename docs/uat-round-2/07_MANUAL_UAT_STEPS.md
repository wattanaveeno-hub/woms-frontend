# 07 — Manual UAT Steps (สำหรับลูกค้า/Owner)

ทำบน UAT ด้วยบัญชีทดสอบ · ข้อมูลที่สร้างตั้งชื่อขึ้นต้น "QA-R2"

1. **ปฏิทินช่าง (01)** — ช่างเปิดคิวที่ได้รับ → "เสนอวันเวลาเริ่ม" → เห็นปฏิทิน 14 วัน → กดวันที่ว่าง → ช่องวันที่เปลี่ยนตาม
2. **นำเข้ารุ่นเครื่อง (02)** — ข้อมูลหลัก > รุ่นเครื่อง → ดาวน์โหลด template → กรอก 2 แถว (1 แถวซ้ำ) → ตรวจ → เห็น ถูกต้อง 1 / ซ้ำ 1 → บันทึก
3. **Login เบอร์ (04)** — ผู้จัดการตั้งเบอร์ให้ช่างที่หน้าผู้ใช้ → ช่างออกจากระบบ → login ด้วยเบอร์ + รหัสผ่าน · ลองตั้งเบอร์เดียวกันให้อีกคน → ต้องขึ้นว่าเบอร์ซ้ำ
4. **ทีมเซลล์ (05/06)** — หน้าผู้ใช้ แถว Sales → "กำหนดทีม" → เลือกทีม → บันทึก → หน้าแชททีมเห็นสมาชิกใหม่ · หน้าเปิดคิว ช่องเซลล์มีชื่อผู้ใช้เซลล์
5. **รูปในแชท (07)** — ส่งรูปในกลุ่ม → กดไอคอนดาวน์โหลดมุมรูป / เปิดรูปใหญ่ → "ดาวน์โหลด"
6. **เปิดคิว (08/09/10/13)** — เปิดคิวงานติดตั้ง → "เลือกเครื่องจากคลัง": ต้องเห็นเฉพาะเครื่องที่ว่างในคลัง, เลือกประเภท/รุ่นแล้วเครื่องไม่หาย → กดเพิ่ม → แถวเป็นสีเขียว "เลือกแล้ว" → เพิ่มรูปหน้างาน 2 รูป → ส่งคิว → หน้าคิวเห็นรูป + "ยังไม่ออก JN" → หลังเปิดงานเห็น JN ที่หัวคิว
7. **ค้นแชท (11)** — ค้นด้วยชื่อคนส่ง / เลขคิว / JN / ชื่อไฟล์
8. **แจ้งเลื่อนงาน (14)** — Admin เปิดใบงานที่ยังไม่เริ่ม → "แจ้งเลื่อนงาน" → ใส่เหตุผล → ระบบพาไปหน้าคิวขั้นเลือกช่าง → ใบงานแสดง "เลื่อนวันเข้า · รอเช็คคิวใหม่" + เหตุผล (ไม่ใช่พักงาน)
9. **รูปหน้างานในใบงาน (15)** — เปิดใบงานที่มาจากคิวข้อ 6 → ส่วน "รูปหน้างาน · คิว …"
10. **สัญญาเช่า (17)** — เปิดสัญญาเช่า > พิมพ์ → ตรวจช่องไฟย่อหน้าสม่ำเสมอ ทั้งบนเครื่อง Windows และมือถือ
