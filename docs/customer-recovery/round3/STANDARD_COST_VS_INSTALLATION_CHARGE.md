# Standard Cost กับ Installation Charge — ข้อกำหนด (Round 3 · การตัดสินใจของเจ้าของโครงการ 30 ต.ค. 2569)

## 1. การตัดสินใจ
เจ้าของโครงการยืนยัน: **2,000 บาทในตัวอย่าง 6 รุ่นของ Equipment Model Master คือ "ต้นทุนมาตรฐาน" (Standard Cost) ใช้เพื่อเปรียบเทียบ — ไม่ใช่ค่าติดตั้ง ราคาขาย หรือรายรับ**
การตัดสินใจนี้แทนการตีความเดิมใน Q-R3-14 (controlled A) ที่ให้ Equipment Model Master เป็นแหล่ง "ราคาติดตั้งมาตรฐาน"

## 2. ค่าที่ต้องแยกกัน
| ค่า | ความหมาย | แหล่ง | ใช้คิดกำไร |
|---|---|---|---|
| Standard Cost (ต้นทุนมาตรฐาน) | ต้นทุนอ้างอิงต่อ ประเภท+หมวดหมู่+รุ่น | Equipment Model Master (`equipment_models.standardPrice` ในฐาน = ต้นทุนมาตรฐาน · API ชื่อ `standardCost`) | **ไม่ใช้** — แสดงเป็นค่าอ้างอิงเทียบกับต้นทุนจริงเท่านั้น |
| Installation Charge (ค่าติดตั้ง) | ยอดที่เรียกเก็บค่าติดตั้ง | Model Index (`meta` kind `model` `.standardPrice` — "ราคาค่าติดตั้งหรือบริการมาตรฐาน") ตาม IDX-01 / MAR-01 | ใช้เป็นรายรับติดตั้ง — **สถานะ: ยังไม่ยืนยัน** |
| Actual Job Costs (ต้นทุนจริง) | ค่าใช้จ่ายที่เกิดจริง | อะไหล่ที่ใช้รายเครื่อง (`job_equipment.partsUsed`) · ค่าบริการช่าง/ค่าใช้จ่ายร่วมจากบิล | ใช้ (ไม่นับซ้ำกับการเบิกสต๊อกระดับใบงาน — D-18) |
| Revenue (รายรับ) | ยอดที่เรียกเก็บได้ | รายรับติดตั้ง (Installation Charge − ส่วนลดรายเครื่อง) + บรรทัดใบเสนอราคาที่ตอบรับ | ใช้ |
| Profit (กำไรบริการ) | รายรับ − ต้นทุนที่เกี่ยวข้องและไม่ซ้ำ | MAR-03 (ไม่รวมราคาขาย/ต้นทุนซื้อเครื่อง/งวดสัญญา) | — |

กติกา: ห้ามใช้ Standard Cost แทน Installation Charge · ห้ามนับ 2,000 เป็นรายรับ · ห้ามบวก Standard Cost เข้าต้นทุนจริง (การรับรู้ต้นทุนเครื่องเต็มจำนวนไม่มีกำหนดในข้อกำหนด → แสดงเป็นข้อมูลอ้างอิงเท่านั้น)

## 3. หลักฐานแหล่งค่าติดตั้ง
- `Claude outputs/WOMS-Requirement-Audit-Report.md` แถว IDX-01: "ตารางรุ่น + ราคามาตรฐาน … ราคาค่าติดตั้ง/บริการ"
- `Claude outputs/WOMS-Requirement-Gap-Closure.md` แถว MAR-01 / BR-10.6: "รายรับติดตั้ง = ราคารุ่น − ส่วนลดรายเครื่อง เมื่อยืนยันงานติดตั้ง"
- `src/domain/master.ts`: Model Index `standardPrice` = "ราคาค่าติดตั้งหรือบริการมาตรฐาน (บาท) — ไม่ใช่ราคาขายเครื่อง"
- ข้อจำกัด: เอกสารทั้งหมดเป็นเอกสารภายในที่อ้างข้อกำหนดของลูกค้า (Refit/Requirement.xlsx) — ไม่มีต้นฉบับของลูกค้าใน repo · **ค่าในตาราง Model Index และกติกาอนุมัติราคาค่าติดตั้งยังไม่ได้รับการยืนยันจากลูกค้า**
→ คง Model Index เป็นแหล่งค่าติดตั้ง (มีหลักฐานโครงสร้าง) แต่ทุกตัวเลขรายรับติดตั้ง/กำไรที่ใช้ค่านี้ติดสถานะ **"ยังไม่ยืนยัน"** · ADV3-01 ยังเปิดในขอบเขตนี้
