# ADV3-01 / Q-R3-14 — ราคาติดตั้งมาตรฐาน: การออกแบบที่ทำ และรายงานกระทบยอด

การตัดสินใจ: **Q-R3-14 Controlled Option A** (SA/PM อนุมัติ 30 ต.ค. 69) — ใช้ Equipment Model Master เป็นแหล่งเดียวของ "ราคาติดตั้งมาตรฐาน" สำหรับงานใหม่
ระดับ ADV3-01 ยังเป็น **High** ตามเดิม (ไม่ลดระดับ) — ส่วนโค้ดแก้แล้ว ส่วนข้อมูลราคายังไม่มีราคาที่อนุมัติ (ดูข้อ 4)

## 1. ปัญหาเดิม
รายรับติดตั้งในหน้ากำไรรายเครื่องคิดจาก Model Index เดิม ส่วนราคาในข้อมูลหลักรุ่นเครื่อง (D-07A) ไม่ถูกใช้ · รุ่นที่สร้างใหม่ไม่มีราคาใน Model Index → รายรับติดตั้ง = 0 โดยไม่มีคำเตือน

## 2. สิ่งที่ทำ (backend `5f2f7dc` + แก้ต่อใน r4fix/r5fix · frontend `b00c0a3`)

## 3. ราคาตัวอย่าง 2,000 บาท — ตรวจแหล่งที่มา
ตรวจเอกสารลูกค้าที่มีในโปรเจกต์ (เอกสาร Round 1–3, คำตอบ D-07, directive 30 ต.ค. 69): ตัวอย่าง 6 รุ่นของลูกค้าระบุ "Standard Price 2,000" แต่ **ไม่มีแหล่งใดระบุว่าเป็นค่าติดตั้ง** (อาจเป็นราคาขาย ราคาเช่า หรือค่าบริการอื่น)
→ ตาม directive ("2,000 THB sample prices are not confirmed installation fees unless the sources say so") ราคาตัวอย่างถูกบันทึกเป็น `UNAPPROVED` และไม่ถูกใช้คิดรายรับ จนกว่า Manager จะอนุมัติว่าเป็นราคาติดตั้งมาตรฐาน · ไม่ได้ตั้งราคาใด ๆ เอง

## 4. ผลต่อการตรวจรับ
- โค้ด: ไม่มีเส้นทางที่ทำให้รายรับติดตั้งงานใหม่เป็น 0 แบบเงียบอีก (ทดสอบใน api-qa-price, e2e-price, unit `installPrice` 18 กรณี)
- ข้อมูล: **ยังไม่มีราคาติดตั้งมาตรฐานที่อนุมัติแม้แต่รุ่นเดียว** → งานใหม่ทุกงานจะขึ้นสถานะ "ยังไม่มีราคาที่อนุมัติ" ในหน้ากำไร จนกว่าลูกค้า/Manager ยืนยันราคา
- จึงยังนับ ADV3-01 เป็น **เปิด (High) ในขอบเขตการตรวจรับการเงิน** จนกว่าจะมีราคาที่อนุมัติ และรายงานกระทบยอดบนข้อมูล UAT ถูกทบทวน (ต้องการข้อมูลจากลูกค้า ไม่ใช่โค้ด) — ดู 10 ข้อ P-01
