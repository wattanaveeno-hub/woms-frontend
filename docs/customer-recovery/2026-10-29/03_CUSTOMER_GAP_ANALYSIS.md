## 4. สิ่งที่ยังไม่ตรงความคาดหวังของลูกค้า (ต้องบอกลูกค้าตรง ๆ)

1. **CHAT-02 แท็กผู้ใช้ (@)** — ยังไม่มี (ต้องยืนยันขอบเขตรายชื่อ/การแจ้งเตือน)
2. **CHAT-03** — การ์ดใหม่ทุกครั้งที่สถานะเปลี่ยน และช่างเสนอวันจากหน้าแชท ยังไม่ทำ (ทำแค่ป้าย PM)
3. **TECH-01 / TECH-02** — หน้าช่างยังแสดงประวัติรอบนัด/บทสนทนา/Log และยังไม่มีปุ่มรับทราบบนการ์ด
4. **TECH-03 / QT-02 / EQ-01 / EQ-02 / AUTH-01 / AUTH-02** — รอคำตอบลูกค้า (11_OPEN_DECISIONS)
5. **BUG-V2-17** — ข้อมูลคลังเครื่อง/สต๊อก/แผนที่ของช่างยังไม่จำกัด "ของตนเอง"
6. **CHAT-01** — ความอ่านง่ายของแชทยังไม่ได้ปรับ
