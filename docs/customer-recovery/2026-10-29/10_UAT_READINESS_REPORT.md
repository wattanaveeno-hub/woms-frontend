## 6. ความเสี่ยงถดถอย

1. **พฤติกรรมคอนเฟิร์มเปลี่ยน** — คิวไม่เปิดงานอัตโนมัติอีกต่อไป ถ้า Admin ไม่รู้จะมีคิวค้างที่ "รอ Admin เปิดงาน"
2. **Sale เสียสิทธิ์ดู** ใบเสนอราคา/เอกสาร/วางบิล/สต๊อก — ถ้าลูกค้าตั้งใจให้ Sale บางคนเห็น ต้องแยกบทบาท
3. **ฐาน PM จากการติดตั้ง** เปลี่ยนวันครบ PM ของเครื่องติดตั้งใหม่ — รายงาน PM ที่อิงวันเดิมจะต่าง
4. **unique index กลุ่มแชท** — ถ้า production มีกลุ่มซ้ำอยู่แล้ว index สร้างไม่ได้และ fix BUG-V2-21 ไม่มีผล (ต้องตรวจตาม 09 ข้อ 3.1)
5. **ทดสอบเฉพาะข้อมูลสังเคราะห์** — ข้อมูลเก่าที่ผิดรูปอาจทำงานต่างไป
6. ไม่มี E2E ครอบคลุม: ปุ่มผูกใบเสนอราคา, dialog แก้คิว/ขอคิวใหม่, หน้าช่าง, วางบิล
