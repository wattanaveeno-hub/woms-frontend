## JobDetail — หลักฐานปิดงาน
ไฟล์: `src/lib/closeEvidence.ts` (+ test 2 ข้อ), `src/components/JobCloseEvidenceCard.tsx`, `src/app/jobs/[id]/page.tsx`

ที่มาของข้อมูล (ไม่สร้างเกณฑ์เอง):
- `GET /api/jobs/:id/close-check` → `canClose`, `reasons`, `machines`, `done`, `signatureRequired` (เกณฑ์ `closeBlockers()` ชุดเดียวกับตอนกดปิดงาน)
- ข้อ “บันทึกเสร็จทุกเครื่อง”, “รูปป้าย SN และรูปงานครบทุกเครื่อง”, “วันที่ติดตั้งเสร็จจริงครบ” = จับคู่ข้อความเหตุผลที่ backend สร้าง (`describePendingLines`, `describeEvidenceGaps`, `describeMissingInstallDates`) · เหตุผลอื่นที่จับคู่ไม่ได้แสดงเป็นข้อแยกตามข้อความจริง
- ลายเซ็นลูกค้า/ช่าง: ระบบเก็บตอนกดปิดงานเท่านั้น (close-check ตัดเรื่องลายเซ็นออก) → ใบงานเปิด = “เซ็นในขั้นปิดงาน (บังคับ)” · ใบงานปิดแล้ว = อ่าน `job.signature` และ `closeSignoffId/closedByName`
- บันทึกจากช่าง = `resultNote` รายเครื่อง + `closeNote`

ทดสอบ (flow13, sandbox): ใบงาน 1 เครื่อง ยังไม่มีหลักฐาน → การ์ดแสดง “ยังไม่ครบ” ตรงกับ close-check และข้อความเหตุผลตรงตัว → แนบรูป SN/รูปงาน + บันทึกเสร็จ → close-check `canClose=true` และการ์ด “พร้อมปิดงาน” → ปิดงานพร้อมลายเซ็นลูกค้า+ช่าง → ทุกข้อ “ครบ” · แท็บเดิมครบ ไม่มี error

ข้อยกเว้น:
1. ไม่มีรูปย่อในแถว checklist — รูปอยู่แท็บ “ปิดงาน & หลักฐาน” (`/photos/summary` ใช้ใน sandbox ไม่ได้)
2. ไม่มีปุ่ม “ขอรูปจากช่าง” — ระบบไม่มี API นี้
3. แท็บ “ประวัติ” และการ์ด “ใบเสนอราคาที่ผูก” — ข้อมูลอยู่ในแท็บ อะไหล่ & การเงิน ตามสิทธิ์ `finance:view`

## Jobs
ไฟล์: `src/app/jobs/page.tsx`, `src/lib/apptRelative.ts` (+ test), `src/components/woms/WomsDataTable.tsx` (prop `rowBg` เสริม — ไม่ส่ง = เหมือนเดิม)
- หัวรอง “N งานที่ต้องทำ · เลยนัด N” · คอลัมน์ เปิดงานเมื่อ / ลูกค้า·พื้นที่ (ชื่อ, สาขา, ตำบล, จำนวนเครื่อง) / งาน (ชื่อ + รหัส + ประเภท) / วันนัดแบบอ่านง่าย (วันนี้/พรุ่งนี้/อีก N วัน/เลยนัด N วัน) / ทีมช่าง / ขั้นงาน / สถานะ / ปุ่ม

ข้อยกเว้น: ไม่มีปุ่ม “ดาวน์โหลด Excel” (ไม่มี API export ใบงาน) · ตัวกรอง ประเภท/ช่วงสัปดาห์ ไม่มีใน API (คงตัวกรอง ทีม/เจ้าของงาน/เซลล์/เรียง)

DEF-R5-01 (เดิม ไม่ได้เกิดจากรอบนี้): รายการใบงานไม่มี stage = SUBMITTED เพราะ backend เก็บ stage แค่ ACKNOWLEDGED/IN_PROGRESS และคำนวณ “ส่งตรวจ” จากรายการส่งงานเฉพาะใน `GET /api/jobs/:id/stage` → แท็บ “รอตรวจปิด” นับได้ 0 เสมอ และปุ่ม “ตรวจปิด” ไม่ปรากฏ · ยืนยันใน sandbox: ช่างส่งงานด้วย `#ส่งงาน` แล้ว `/stage` ตอบ SUBMITTED แต่รายการยังเป็น IN_PROGRESS
